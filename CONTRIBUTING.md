# Contributing to Digital Passbook 💼

Thank you for considering contributing to **Digital Passbook**! Contributions from the community help make this project better for everyone.

---

## 📌 Ways to Contribute

- **Report Bugs**: If you find an issue, please open an Issue with steps to reproduce and system/browser info.
- **Suggest Features**: Have an idea for a new feature (like dark mode, monthly budgets, or CSV exports)? Open an Issue to discuss!
- **Submit Pull Requests**: Fix a bug, improve UI/UX, or implement a requested feature.
- **Improve Documentation**: Enhance guides, write examples, or fix typos in docs.

---

## 🚀 Getting Started

1. **Fork the Repository**  
   Click the **Fork** button at the top right of this repository.

2. **Clone your Fork locally**
   ```bash
   git clone https://github.com/dhruvil-114/web-passbook.git
   cd web-passbook
   ```

3. **Create a Feature Branch**
   ```bash
   git checkout -b feature/your-feature-name
   # or
   git checkout -b fix/bug-description
   ```

4. **Make Your Changes**  
   Open `index.html` in your browser (or use VS Code Live Server). Test your changes thoroughly in both **Demo Mode** and **Admin Mode** (if Firebase is configured).

5. **Commit Your Changes**  
   Write clean, descriptive commit messages following the Conventional Commits style:
   ```bash
   git commit -m "feat: add dark mode theme toggle"
   ```

6. **Push to Your Branch**
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request**  
   Go to the original repository and click **Compare & pull request**. Provide a clear summary of your changes.

---

## 📋 Coding Guidelines

- Keep code clean, readable, and well-commented.
- Maintain the lightweight, vanilla nature of the project (HTML5, CSS3, vanilla JavaScript).
- Ensure mobile responsiveness is preserved across screen sizes.
- Never commit actual API keys or sensitive Firebase credentials.
